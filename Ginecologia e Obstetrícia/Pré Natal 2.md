# Pré- Natal
- **Mínimo de Consultas**: Mínimo de 6
- **Agendamento de Consultas Ideal**:
	- *IG 0-28s*: Consultas Mensais
	- *IG 28-36s*: Consultas Quinzenais
	- *IG 36-41s* Consultas 
	- *Puerpério*: 1 consulta com 7d pós-parto e 1 no fim do puerpério 
## Anamnese
- **Identificação**:Nome, idade, GxPxAx, DUM, IG, Motivo de Indicação de PNAR (se for o caso), Risco do Pré-Natal, Medicamentos, Diagnósticos
- **Queixa Principal**: Sem queixas = Pré-Natal
- **HMA**:Além da queixa principal, perguntar sintomas gravídicos
	- *Sintomas Gravídicos de 1º Trimestre*:Dor na mama, cefaleia, náuseas, vômitos, tontura, fadiga, pirose, sialorreia, ptialismo, perda ou ganho de peso, diminuição da libido, sangramentos, acne, leabilidade emocional, diurese frequente
	- *Investigar no 2º Trimestre*: Fraqueza / desmaio (hipotensão), Dor abdominal cólica, flatulência, constipação intestinal, sangramento gengival, dispneia, epistaxe, poliaciúria, caimbras, corrimentos, sonolência, crescimento uterino
	- *Investigar no 3º Trimestre*: Dor lombar, varizes e hemorroidas, Cloasma gravídico, estrias, desconforto para dormir, dispneia, edema, ganho de peso, cansaço
- **HPP**:
	- *Rastrear Antecedentes Pessoais*: HAS, DM, transfusões, anemias, doenças infecciosas, alergias, doenças neuropsiquiátricas, tireoidopatias, cardiopatias, doenças renais, asma, cirurgias prévias, grandes traumatismos prévios
	- *Rastrear Antecedentes Familiares*: HAS, pré-eclampsia, eclampsia, Doenças congênitas, Gemelaridade, Cancer de mama, Doenças infectocontagiosas
	- *Rastrear Hábitos e Estilo de Vida*: Tabagismo, Etilismo, Drogas ilícitas, atividade física, qualidade do sono
	- *Fármacos e Suplementação*: Fármacos e suplementação utilizada atualmente
- **Antecedentes Ginecológicos**: Menarca, Sexarca, padrão menstrual prévio, DSTs, infertilidade ou esterelidade, doenças ginecológicas prévias, cirurgias ginecológicas prévias, parceiro fixo?, uso de DIU, Momento da última mamografia e preventivo
- **Antecedentes Obstétricos** (Fazer no formato abaixo)
	- *Gx*: Data do parto, IG no Parto, Via de parto, intercorrências, uso de medicações, outras informações úteis
- **Calcular Risco do PN**
- **Verificar Cartão Vacinal da Gestante**
- **Preencher Cartão da Gestante**
## Exame Físico PN Dirigido
- **ACV**: PA + FC + Descrição das bulhas
- **AP**: FR + Descrever murmúrios 
- **IMC + Ganho Ponderal**
- **Ectoscopia**: Cabeça, Pescoço, tireoide, edema em MMII
- **Exame Abdominal Simplificado**: Palpar órgãos (figado, baço e útero)
- **Exame de Mamas**
- **Altura Uterina**
- **BCF**: A partir da 12s-16s (teoricamente a partir das 10s já dá, mas é mto dificil)
- **Movimentação Fetal**
- **Manobras de Leopold-Zweifel**: Apenas a partir das 34s (3º triméstre)
- **Especular (Se necessário)**
- **Toque Vaginal (Se indicado)**
## Suplementação Profilática
- **Ácido Fólico**: Desde 1-3m pré-concepção até o fim da gestação 0,4-0,8mg/d. Se fator de risco 4-5 mg/d
- **Sulfato Ferroso**: A partir do descobrimento da gravidez até 3m pós-parto 40-60 mg/dia (Dose terapêutica: 200-300mg)
- **Vitamina D** Manter acima de 30-60ng/dl 1000 UI/dia
- **Se Risco Aumentado de Pré-Eclampsia** AAS ver [[Distúrbios Hipertensívos na Gestação]]
## Exames Preconizados na Gestação
- **1º Trimestre**:
	- HMG
	- Fe e Ferritina
	- Tipo ABO + FRh + Coombs Indireto
	- GJ + HBA1C
	- EAS + Urocultura + Antibiograma
	- TSH
	- VDRK e FTAbs
	- Teste Rápido HIV
	- Toxoplasmose (IgM e IgG)
	- HBsAg (Anti-HBs + = Imunidade pra Hepatite B)
	- Anti-HCV
	- Rubéola e CMV (IgG e IgM)
- *Exames Complementares (Não Obrigatórios)*
	- Colpocitologia Oncótica (apenas se necessário)
	- Exame de secreção vaginal
	- Parasitologico de Fezes
	- Eletroforese de Hemoglobina (Detecta anemia falciforme, doença hemolítica e talassemia)
	- Proteinúria (Normalmente se faz em hipertensas
- **2º Trimestre**
	- TOTG 75g (Se GJ < 92 no 1º tri) (Fazer entre 24-28s
	- Coombs Indireto (Se Rh negativo)
	- Ecocardiograma Fetal (Até 28s) se: HF de cardiopatia congênita, idade >35, Diabetes, infecções maternas– rubéola, cmv, etc– uso de drogas teratogênicas ou indutoras do fechamento do canal arterial e presença de lúpus ou anti-Ro+
- **3º Trimestre**
	- HMG
	- Coombs Indireto (Se Rh negativo)
	- Sifilis
	- Teste Rápido - HIV
	- HBsAg
	- Toxoplasmose (se suceptivel)
	- EAS + Urocultura
	- Cultura para Streptococcus do Grupo B (entre 36-37s + 6d)
	- HTLV (Contraindica aleitamento)
## Ultrassonografias no Pré-Natal
- **1º Trimestre**:
	- *IG 6-9s*: USG Obstétrica de 1º Trimestre via vaginal
	- *IG 11-14s*: USG Morfológica de 1º Trimestre via abdominal
- **2º Trimestre**
	- *IG 18-24s*: USG Morfológica de 2º trimestre
- **3º Trimestre**
	- *IG 34-36s*: USG Obstétrica de 3º Trimestre
[[Assistência Pré-Natal]]
## Vacinas na Gestação
- **Vacinas Indicadas**
	- *Influenza*: Qualquer momento, sazonal
	- *Coronavirus*: Qualquer momento, 2 doses anuais com 6m de intervalo
	- *Hepatite B*: Apenas após confirmar Anti-HBs negativo, ai vacina no esquema: 0-1-6 meses
	- dTpa: A partir da 20ª semana
	- *Vírus Sincicial Respiratório*: entre 32-36 semanas
- **Vacinas Indicadas Apenas em Situações Especiais**: Febre Amarela, Hepatite A, Pneumococcica, Meningocóccica ACWY ou C, Meningocócica B, Varicela (pós-parto), Raiva, Anti-Rh
- **Vacinas Contraindicadas na Gestação**: HPV, Triplice Viral, Varicela, Dengue, BCG, VOP

        const valDum = container.querySelector('#input_val_dum').value;
        if (!valDum) {
            new Notice("Por favor, selecione a data da DUM.");
            return;
        }
        dumTeorica = moment(valDum);
        dpp = dumTeorica.clone().add(280, 'days');
        igDias = hoje.diff(dumTeorica, 'days');
        margemErro = "± 14 dias (2 semanas)";
    } else {

        const sem = parseInt(container.querySelector('#input_usg_sem').value) || 0;
        const dias = parseInt(container.querySelector('#input_usg_dias').value) || 0;

        if (!valUsg) {
            new Notice("Por favor, selecione a data do USG.");
            return;
        }

        const dataUsg = moment(valUsg);
        const totalDiasUsg = (sem * 7) + dias;
        
        dumTeorica = dataUsg.clone().subtract(totalDiasUsg, 'days');
        dpp = dumTeorica.clone().add(280, 'days');
        igDias = hoje.diff(dumTeorica, 'days');

        if (sem < 14) {
            margemErro = "± 5 a 7 dias (USG 1º Trimestre)";
        } else if (sem < 28) {
            margemErro = "± 10 a 14 dias (USG 2º Trimestre)";
        } else {
            margemErro = "± 21 dias / 3 semanas (USG 3º Trimestre)";
        }
